# Foto Estudio Mario - Portfolio Website

A static website portfolio for Foto Estudio Mario, showcasing photography services including digital photography, background changes, restoration, printing, and enlargement services.

## Features

- Responsive design with dark grey theme
- Service showcase
- Photo gallery with filtering
- Before/After comparison for restoration services
- Contact form
- About page with team information
- Mobile-friendly layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome icons
- Lightbox for gallery images

## Deployment Instructions for GitHub Pages

1. **Create a GitHub Repository**
   - Sign in to your GitHub account
   - Click on the "+" icon in the top right corner and select "New repository"
   - Name your repository (e.g., "foto-estudio-mario")
   - Choose "Public" visibility
   - Click "Create repository"

2. **Initialize Git in your local project folder**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```

3. **Connect your local repository to GitHub**
   ```bash
   git remote add origin https://github.com/yourusername/foto-estudio-mario.git
   git branch -M main
   git push -u origin main
   ```

4. **Enable GitHub Pages**
   - Go to your repository on GitHub
   - Click on "Settings"
   - Scroll down to the "GitHub Pages" section
   - Under "Source", select "main" branch
   - Click "Save"
   - GitHub will provide you with a URL where your site is published

5. **Access Your Website**
   - Your website will be available at `https://yourusername.github.io/foto-estudio-mario/`
   - It may take a few minutes for your site to be published

## Customization

To customize this website for your needs:

1. Replace placeholder images in the `images` folder with your own images
2. Update contact information in the footer and contact page
3. Modify service descriptions and pricing in the services page
4. Add your own gallery images and update the gallery items
5. Update team information in the about page

## Image Requirements

For optimal performance, prepare your images as follows:

- **Hero Image**: 1920x1080px
- **Service Images**: 800x600px
- **Gallery Images**: 800x600px
- **Team Photos**: 400x600px
- **Before/After Images**: 800x600px

## Local Development

To view the website locally, simply open the `index.html` file in your web browser.
